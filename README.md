## Module Descriptions

### Module 0 — Introduction to Shell and Python

Focus: terminal navigation, file creation, and first Python scripts.

Exercises: create the `discovery_piscine` directory structure, write `42.py` (prints `42`), and `hello_world.py` (prints `Hello World`).

### Module 1 — Variables and User Input

Focus: variable assignment, string concatenation, arithmetic, and basic input/output.

Exercises: `name.py` (display first and last name), `age.py` (age + 42), `whatsyourname.py` (prompt for full name).

### Module 2 — Conditions

Focus: `if`, `elif`, `else`, comparison operators, and logical flow.

Exercises: `iszero.py` (check zero), `isneg.py` (positive/negative/zero), `password.py` (password check), `mult.py` (multiplication sign and result).

### Module 3 — Loops

Focus: `while` loops, `for` loops, `break`, and iteration.

Exercises: `to25.py` (count to 25), `multiplication_table.py` (single multiplication table), `i_got_that.py` (loop until STOP), `advanced_mult.py` (all tables 0–10 with two while loops).

### Module 4 — Simple Objects and Type Conversion

Focus: integers, floats, strings, type casting, and basic arithmetic.

Exercises: `upcase_it.py` (uppercase input), `age.py` (age progression), `calculator.py` (four operations), `float.py` (integer vs decimal), `round_up.py` (ceiling), `up_low.py` (swap case).

### Module 5 — Lists

Focus: list creation, iteration, `append`, `set`, and `sys.argv`.

Exercises: `create_list.py` (define and print list), `play_with_lists.py` (add 2 to each element; then filter >5; then deduplicate with set), `parameters.py` (count command-line arguments).

### Module 6 — Arrays and Command-Line Arguments

Focus: `sys.argv`, string methods, loops over arguments.

Exercises: `aff_first_param.py` (first argument), `upcase_it.py` (uppercase single argument), `downcase_it.py` (lowercase single argument), `aff_rev_params.py` (reverse all arguments), `scan_it.py` (count keyword occurrences).

### Module 7 — More Arrays and String Manipulation

Focus: `len()`, `for` loops, `range()`, string methods like `find`, and list building.

Exercises: `parameter_matching.py` (match user input to argument), `count_it.py` (display parameters and lengths), `string_are_arrays.py` (print all `z` characters), `append_it.py` (append `ism` unless already ends with `ism`), `free_range.py` (build range list between two numbers).

### Module 8 — Functions and Scope

Focus: function definition, parameters, default arguments, return values, and local vs global scope.

Exercises: `hello_all.py` (define and call `hello`), `upcase_it.py` (function `upcase_it`), `downcase_all.py` (function `downcase_it` applied to arguments), `greetings_for_all.py` (function with default parameter and type check), `functions_everywhere.py` (`shrink` and `enlarge` functions), `scope_that.py` (demonstrate scope).

### Module 9 — Dictionaries

Focus: dictionary creation, iteration, `filter`, `sorted`, and nested dictionaries.

Exercises: `your_namebook.py` (build full names from dictionary), `family_affairs.py` (filter redheads), `help_your_professor.py` (compute class averages), `persons_of_interest.py` (sort historical figures by birth date).
